What this version optimizes

Members’ declared plans are taken in good faith. Everyone can contribute without a buff. Inventory is context; it is not the points an appointment creates.

The default gives as many members as possible a first appointment, then maximizes measured extra benefit, then covers requested days and preferences, rotates access using supplied history and preserves prior draft times. If some eligible requests lack benefit estimates, all benefit ranking is disabled: the planner covers more requested days, preferences and history instead. Benefit-first requires complete estimates. With complete estimates, the result compares broad access with the greatest measured benefit. All policies use exact matching within this three-day model.

Optional columns: “Construction preferred UTC”, “Construction unavailable UTC”, “Construction buff benefit minutes” (and Research / Training equivalents), plus “Prior appointments”. Benefit minutes mean additional time saved by the title over the same plan without it, with shared general speedups already allocated once. Leave unknown benefits blank. This survey planner does not simulate task chains; use the advanced plan optimizer for coupled tasks, multiple offices and resource budgets.
